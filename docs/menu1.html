ルール

  1. 初期状態: 石はゲーム開始時に 20個から30個の間でランダム に置かれます。
  2. プレイヤー: プレイヤーAとプレイヤーBが交互に石を取ります。
  3. 勝利条件: 最後に残った石を取った人が「勝ち」です！
  4. ターンごとのルール:
    • 取れる石の最小数は常に1個です。
    • 取れる石の最大数は、前のプレイヤーが取った石の数の「2倍」までです。
    • ただし、最初のターン（前のプレイヤーがいない時）のみ、最大3個まで取れます。

ルール適用

1. ゲーム開始時 (Aさんの最初のターン):

Aさんは 1個 2個 3個 の中から選べます。

2. Aさんが2個取った後、Bさんのターン:

Bさんはその2倍、つまり 最大4個 まで取れます。
